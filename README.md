# INAOE Xalitzintla

Agriculture monitoring platform with integrated mobile app, web dashboard, and IoT hardware sensors.

## Project Structure

- `/mobile-app` - Flutter mobile application (FlutterFlow)
- `/web-app` - React web dashboard
- `/hardware` - Raspberry Pi sensor code (Python)
- `/database` - Supabase schema and migrations
- `/docs` - Project documentation

## Tech Stack

- **Mobile App**: FlutterFlow (Flutter + Dart)
- **Web App**: React
- **Database**: Supabase (PostgreSQL)
- **Hardware**: Python (Raspberry Pi + Sensors)

## Getting Started

See individual README files in each directory for setup instructions.
