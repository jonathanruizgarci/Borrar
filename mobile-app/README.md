# Mobile App (FlutterFlow)

Flutter-based mobile application for agriculture monitoring.

## Structure

- `/lib` - Main application code
  - `/screens` - UI screens
  - `/widgets` - Reusable components
  - `/services` - API and database services
  - `/models` - Data models
  - `/utils` - Utility functions
- `/assets` - Images, fonts, etc.
- `/exports` - FlutterFlow exported code

## Setup

1. Install Flutter SDK
2. Configure FlutterFlow project
3. Connect to Supabase backend
4. Run `flutter pub get`
5. Run `flutter run`
