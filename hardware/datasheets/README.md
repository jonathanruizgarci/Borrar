# Sensor Datasheets & Documentation

This folder contains technical documentation for all sensors used in the project.

## Contents

Store the following documentation here:
- Sensor datasheets (PDF)
- Wiring diagrams
- Calibration procedures
- Pinout specifications
- Communication protocols (I2C, SPI, analog, etc.)

## Recommended Sensors

### Temperature & Humidity
- **DHT22** - Digital temperature and humidity sensor
- **BME280** - Temperature, humidity, and pressure sensor

### Soil Moisture
- **Capacitive Soil Moisture Sensor** - Corrosion-resistant
- **Resistive Soil Moisture Sensor** - Budget option

### Light
- **BH1750** - Digital light sensor (I2C)
- **Photoresistor (LDR)** - Analog light sensor

### Additional Sensors (Optional)
- **pH Sensor** - Soil pH measurement
- **NPK Sensor** - Soil nutrients (Nitrogen, Phosphorus, Potassium)
- **Rain Sensor** - Precipitation detection

## File Naming Convention

Use descriptive names:
- `DHT22_datasheet.pdf`
- `capacitive_soil_moisture_wiring.png`
- `BH1750_calibration_guide.pdf`
